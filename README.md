Клиентский Fabric-модификатор для Minecraft SMP-сервера **TSF**. Предназначен для бесшовного управления несколькими игровыми аккаунтами, авторизации через собственный сервер авторизации (`tsf-auth`) и обеспечения безопасности на стороне игрового клиента.

---

## 🚀 Основной функционал

### 🔄 Менеджер аккаунтов (Account Switcher)
* **Интерфейс**: Встроенный кастомный GUI-экран (`AccountListScreen`), позволяющий добавлять, переключать и удалять аккаунты прямо внутри запущенного клиента игры без её перезапуска.
* **Авторизация**: Полная интеграция с Authlib Injector для поддержки авторизации на приватном сервере TSF.

### 📡 Синхронизация сессии и Античит-сканирование
* **Защита сервера**: При подключении к серверу мод обменивается кастомными пакетами по сетевому каналу `tsfauth:session_sync` (через Fabric Networking API).
* **Списки модов**: Мод асинхронно собирает сведения обо всех установленных на стороне клиента Fabric-модификациях (их ID, версии, метаданные) и отправляет их серверному плагину для валидации и выявления запрещённых чит-клиентов/эксплойтов.

### 🛡️ Фоновый авторефрешер (`TokenRefresher`)
* **Автоматическое обновление**: Запускает периодическую фоновую задачу для проверки валидности авторизационных токенов. Токены автоматически обновляются до истечения срока их действия, предотвращая вылеты из сессий во время долгого отсутствия активности.

### 👕 Предварительная загрузка скинов (`SkinFetcher`)
* **Оптимизация**: Асинхронно скачивает и кэширует скины для всех добавленных в менеджер аккаунтов во время запуска игры.

## 🛠️ Сборка и обфускация (Информация для разработчиков)

Проект использует многоуровневую систему сборки через Gradle с интеграцией кастомной обфускации.

### Основные задачи сборки:
1. **Генерация констант (`generateConstants`)**: Перед компиляцией генерируется класс `BuildConstants.java`, содержащий зашифрованную информацию о версии, сервере авторизации и хэшах.
2. **Обфускация строк (`stringObfuscator`)**: Кастомный Gradle-таск, который шифрует строковые литералы в скомпилированном `.jar` файле алгоритмом XOR с ключом `0x42` для усложнения реверс-инжиниринга.
3. **Сокращение кода и ProGuard (`proguard`)**: Выполняет оптимизацию байт-кода, удаление неиспользуемых частей и обфускацию структуры классов на основе правил из [proguard-rules.pro](file:///D:/Projects/Java/tsf%20smp/mod/proguard-rules.pro).
4. **Контрольная сумма (`printHash`)**: По завершении сборки вычисляет и выводит SHA-256 хэш-сумму финального обфусцированного файла `tsf-auth-<version>-obfuscated.jar`. Серверный плагин допускает в игру только те клиенты, SHA-256 хэш мода которых совпадает с эталонным.

### Команда сборки:
```bash
./gradlew build
```
Итоговый файл для распространения игрокам находится по пути:
`build/libs/tsf-auth-<версия>-obfuscated.jar`
